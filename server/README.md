# 自宅サーバーで使うもの

どれも `~/kz`（このリポジトリの写し）の `server/` にあります。ふだんのユーザー（docker を使える人）で動かします。root では動かしません。

| もの | すること |
|---|---|
| `kanri.py` | **サーバー管理のアプリ（窓）**。ようす（機械・コンテナ・DB・定時の処理・API）、更新（update.sh・w5.sh をボタンで）、バックアップ（一覧・いま取る・けす）、記録。ひらくたびにアプリのパスワード、15分さわらないと鍵がかかる |
| `kanri_setup.sh` | はじめに1回：python3-tk（窓を出すもの）を入れて、アプリ一覧とデスクトップに「風の芽 管理」のアイコンを置く |
| `update.sh` | DB の更新（`supabase/migrations`）を入れる。GitHub の main を取ってきて、バックアップを取ってから、まだのものだけを入れる。GitHub の履歴を新しくしたとき（前の履歴とつながらない）は、いままでの履歴をこの PC のブランチ `rireki-日時` と `~/kz-backups/rireki-日時.bundle` にのこしてから合わせる |
| `rehash.txt` | 入れたあとで中身を書きかえた更新（実在の名前をのぞいた など）の、名前・前の sha256・いまの sha256。ここにある書きかえだけは、update.sh が止まらずに通す |
| `report.sh` | サーバーのようすを短くまとめる（Claude に貼る用。所持金・国庫の数・メールアドレス・鍵は出さない） |
| `w5.sh` | 国土を 5×5 に広げる（1回だけ。データのファイルは ~/kz-w5 かダウンロードのフォルダに置く） |
| `oauth.md` | Google・Discord でログインできるようにする手順（Google・Discord のアプリ・`.env`・`docker-compose.yml`・たしかめかた。秘密は `.env` にだけ） |

## 管理アプリ

```
bash ~/kz/server/kanri_setup.sh     # はじめに1回
```

アイコンの「風の芽 管理」でひらきます（`python3 ~/kz/server/kanri.py` でも）。

- はじめてひらいたときに、アプリのパスワードを決めます（Ubuntu のパスワードとは別のもの）。ハッシュだけが `~/.config/kz-kanri/pass` にのこります
- パスワードをわすれたときは、`~/.config/kz-kanri/pass` をけすと、つぎにひらいたときに決めなおせます（Ubuntu にログインできる人だけができる）
- サーバーの中だけで動きます（ネットに何も出しません）。リモートデスクトップでひらいて使います
- 更新・バックアップは、アプリをとじても止まりません（`~/kz-backups/jobs/` に記録しながら動き、つぎにひらくと続きのようすが見られます）
- アプリでやったことは `~/kz-backups/kanri.log` にのこります
- 国庫・お金／人と権限／設定は、これから足します（Web の管理画面から危ない操作をうつす）
