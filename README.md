  - **待避・続行**：種別ごとに**優先番号**（0〜9。0 がいちばん優先。はじめは 特急1・急行2・快速3・各停5・回送と試運転8）。系統の画面の「**種別と優先番号**」で変えたり、種別を足したりできます（名義ごと・ぜんぶの系統で使う）。同じ系統・同じ向きで、優先番号の大きい列車は、うしろから来る優先番号の小さい列車に追いつかれる前に、**待避できる駅**（その向きで使える番線が2つ以上ある駅）の待避線で待ちます（**待避**）。追いつく列車は、前の列車のうしろ 30m（線路の**信号**を強くすると 20m・10m）まで近づけるように駅で待ちます（**続行**）。同じ番号なら先に出る列車が先。時刻は自動でずれ、一覧に「待避 ○○：先に通す列車 201（1分12秒）」「続行 ○○：前の列車 102（40秒）」と出ます
  - **信号**（線路をタップ →「**🚦 信号**」）：**自動閉塞**（ふつう・はじめはこれ）・**ATC**（車内信号）・**移動閉塞** からえらべます。強いほど前の列車につめて走れます（前の列車のうしろ 30m → 20m → 10m。駅のあたりでも速いまま つめられる）。待避・続行の待ちが へります（駅で止まる列車どうしは、止まっている時間が大きいので、差は数秒）。工事費は上げる分だけ（1マス：ATC は線路の工事費の 0.4倍・移動閉塞は 0.8倍。複線はその倍率。国の線は無料）。下げるのは無料（返金なし）。維持費は変わりません。「分かれ道までの つながる線路も いっしょに」で まとめて変えられます。駅と駅のあいだは、通る線路のうち いちばん弱い信号で見ます。信号のちがう線路のつなぎ目は、1本にできません
  - **複々線**（線路をタップ →「複線・電化・名前・色」→ 複々線。引くときにも えらべます）：急行線と緩行線の2つの複線です。優先番号 3 まで（特急・急行・快速）の列車は急行線、4 から（普通・回送など）は緩行線を走り、複々線の駅と駅のあいだでは、たがいに追いこし・追いこされを見ません（待避しなくてよい）。同じ線の列車どうしは、ふつうどおり待避・続行します。複々線の中の駅では、急行線の列車は待避線の番線（3・4番線など）に止まるので、駅は4番線以上にしてください。工事費は複線の 1.7倍、維持費も多く、はばも広くなります（広げるところに建物があると できません）。複線と複々線のつなぎ目は、1本にできません
  - **電化方式**（線路をタップ →「複線・電化・名前・色」→ 電化方式。引くときにも えらべます）：**直流**（1500V。いまの電化した線はこれ）・**交流50Hz**・**交流60Hz**（20kV）。方式がかわるところは**デッドセクション**（地図に黄と黒のしるし）で、電気が来ないので惰行で通ります（1か所 6秒おそくなる）。車両は走れる方式がきまっていて（いまの電車・電気機関車は直流。178系・378系・462系・EF88形は交直流で3つとも、772系・ED96形は交流50Hz・60Hz）、走る区間の方式を走れない編成は、注意が出て走りません（気動車・ディーゼル機関車・蒸気機関車は どこでも走れます）。電化方式を変えるのは 1マス 電化の工事費の 0.6倍。方式のちがう線路のつなぎ目は、1本にできません
  - **変電所**（電化した線路をタップ →「**⚡ 変電所**」）：電化した線路には、変電所から電気をとどけます。とどくのは、同じ持ち主・同じ方式の線路で、**直流は 10km・交流は 40km** まで。電気が来ていない線路（地図に赤の点線。線のシートの「電気」）を通る電車は、注意が出て走りません。いまの電化した線路には、変電所を自動でおきました（無料・大きめ）。大きさは **小・中・大**（容量 直流 3,000・6,000・12,000kW、交流 10,000・20,000・40,000kW。工事費 直流 6,000万・1億1,000万・2億 X、交流は少し高い。維持費 1日 2万〜6万 X、交流は2割高い）。1時間ごとに変電所の**負荷**（そこから電気をうけとる線路を走った電車の出力から）を計算し、**容量をこえると電圧の低下**（徐行・遅れ）、**1.5倍をこえると変電所の停止**（運転見合わせ 45分）が起きます（運行情報の理由に出ます。1つの変電所で3時間に1回まで）。列車の多い線は大きく、長い線は とちゅうにもう1つ。変電所の受けもちがかわる点は**エアセクション**（地図に青のしるし）。変電所をタップすると、容量・負荷を見て、大きさ・名前を変えたり、こわしたり（返金なし）できます
  - **ほかの系統と待避・続行**：系統の画面のボタンでオン（はじめはオフ）。同じ駅を通るほかの系統（乗り入れの他社の列車もふくむ）の、優先番号の小さい列車（同じなら系統の番号の小さいほう）にもゆずります。**重なりを直す**：同じ駅・同じ番線に重なる列車を、番線のふりかえ・時刻のずらし・両方で直します（見つもってから。ゆずるのは優先番号の大きい列車。ほかの系統と重なるときは、この系統の列車）
  - **重なりを直す**（系統の画面）：同じ駅の同じ番線に重なる列車を、番線のふりかえ・時刻のずらし（前の駅で待つ）で直します。見つもってから直し、あとで「↶ 取り消す」でもどせます。列車の多い系統は、40秒ずつ何回かに分けて、のこりも つづけて直します（「とめる」で やめられます。取り消すと、何回に分けても1回で直す前にもどります）。見つもりは、とちゅうまでのことがあります
  - **駅の順を直す（途中に入れる）**（系統の画面）：駅の「＋」をおすと、そのあとに駅を入れられます（「いちばん前に入れる」も）。とちゅうに足した駅には、いまの列車も止まります（通過させるときは「停車駅のパターン」）
  - **支線**（系統の画面の「＋ 支線をつくる」）：本線の駅から分かれる系統をつくります。分かれる駅をえらび、「支線だけ」か「本線のはじめ（さいご）の駅から直通」をえらぶと、本線の駅を入れた状態で系統づくりが始まります（つづけて支線の駅をタップ）。支線は本線とはべつの系統で、系統の一覧では本線の下（└ 支線）に、ダイヤには「本線は ○○（分かれる駅：△△）」と出ます。直通する列車は支線の系統の列車で、途中始発・途中止まりにもできます。鉄道は、本線と支線の「ほかの系統と待避・続行」がオンになります（同じ線路で、優先番号の小さい列車に たがいにゆずる）。「支線をやめる」で、ふつうの系統にもどせます
  - **AIで編集**（系統の画面の「🤖 AIで編集」）：ダイヤを、AI（Claude など）にわたせる文字にして書き出します。AI むけの説明（答えの書き方・ダイヤのきまり）と、駅（km・番線・待避できる駅・採時駅）・単線の区間・種別と優先番号・停車駅のパターン・運用・標準の所要時間・列車の一覧（1行に1本の JSON）が入っています（向きと始発の時間でしぼれる）。「コピー」か「ファイルで保存」で AI にわたし、「朝の快速を10分おきにして」のように たのみます。AI の答え（```jsonl のところ。全部貼ってもよい）を貼って「見つもる」→「取りこむ」。書いた列車だけ直す（id のある列車を直す・id のない列車を足す・del で消す）か、まるごと入れかえ（書かなかった列車は消える）をえらべます。まちがいは行ごとに出て、1つでもあれば何も変えません。見つもりでは、重なり・走れない列車の数と、注意の出る列車が出ます。取りこんだあとも「↶ 取り消す」でもどせます
  - **発着番線**：地図で駅に近づくと、ホームの中に番線の番号（1・2…）が出ます。駅をタップ →「発着番線」で、番線ごとに 下り・上り・両方 と 本線・待避線 を決めます（はじめは 1番線 下り本線・2番線 上り本線・3番線から 下り／上りの待避線。1番線だけの駅は上下の本線）。列車はその向きの本線に止まり、待避するときは待避線へ。採時駅で番線を決めた列車はその番線
  - **番線ごとに優先する種別**（DB の更新115）：「発着番線」（ホームの形）の画面で、番線ごとに 優先する種別（特急・普通など。この駅を通る列車の種別のボタンと ＋ で ほかの種別も。8つまで）をえらべます。列車の番線は、その種別の番線 → 決めていない番線 → ほかの種別の番線 の順にえらびます（待避する列車は 待避線が先。採時駅で番線を決めた列車は そのまま）。駅の画面の発着番線に「（優先：特急・急行）」と出ます
  - **停車駅のパターン**：系統の画面の「停車駅のパターン」で、種別ごとに通過する駅を決めておけます（例：快速は○○と△△だけ止まる）。列車をつくる・まとめてつくる・種別を変えるときにそのパターンになり、「この種別の列車にも当てはめる」で、いまある列車もまとめて変えられます（取り消せる）。端の駅も通過にでき、止まる最初の駅が始発、最後の駅が終着になります（列車には、その列車の走る区間のうちで当てはめる。止まる駅が2つ以上のこらない列車はそのまま）
  - **1時間の型（パターンダイヤ）**（DB の更新104）：系統の画面の「⏱ 1時間の型」。行ごとに 種別・向き（下り・上り・両方）・発車の分（例：00, 15, 30, 45。「1時間に何本」で等間隔）・走る区間・列車番号の頭 を決めて、何時から何時まで くりかえして1日のダイヤを組みます。停車駅は 種別の停車駅のパターン。その時間帯の列車を消して つくりなおすこともでき、「↶ 取り消す」でもどせます。型は系統に のこり、つぎに開いたときに出ます。列車番号は 向きごとに発車の順（時×100＋下り 1・3・5…／上り 2・4・6…）
  - **まとめてつくる**：種別のとなりの「停車駅のパターン」で、その種別の止まる駅を そのまま直せます
  - **乗り入れ（他社直通）**：ほかの人・会社の駅か線路をタップ →「乗り入れを申請」（ひとことをつけられる）。持ち主に通知がとどき、≡ →「🔀 乗り入れ」で **許可**（線路使用料：1列車・1km。はじめは 1,000 X）か **ことわる**。許可されると、系統に持ち主の駅を入れられ（系統をつくるときに「（乗り入れ）」）、道すじは自分の線路と持ち主の線路から見つけます。線路を持ち主の線路につなぐこともできます（どちらかの向きに許可があれば）。運賃は系統の持ち主に入り、1時間ごとに、走った列車（回送・試運転もふくむ）× 持ち主の線路の km × 使用料が、系統の持ち主から線路の持ち主へ（お金の記録は「使用料」）。同じ駅の番線は、ほかの持ち主の列車ともかさならないように見ます。持ち主は使用料を変えたり、**やめる**ことができ、やめると持ち主の線路・駅を使う系統は走れなくなります（乗り入れる側も、やめる・申請の取り消しができます）。持ち主の線路を直したときも、乗り入れている系統の道すじを見なおします

  - **いちばん速い道を自動で選びます**：ホストが1秒ごとに、人ごとに道ごとの往復の時間をはかって選び、相手に知らせます（試合の通信だけ。部屋の知らせなどは、直接かMQTT）。直接がよければ直接（中継は使わない）。直接がない・遅い（90msより）ときだけ中継をはかって、速ければ中継を使います。試合中は左上に「🌐 45ms・中継」のように往復の時間と道が出ます（部屋の画面にも）。入力のおくれも、選んだ道の速さに合わせて自動で調整します
  - 中継（Supabase Realtime）は通数に上限があります（無料プラン：1秒に100通・1か月200万通。送った1通＋受けとった人数でかぞえる）。通数をへらすため、試合の通信は少しまとめて送ります（参加者1人あたり80msごと。中継を使う人が多いと人数ぶんのばす。ホストは入力が届いたらすぐ返す）。2人の試合で中継を使うと1秒に約50通（3分で約1万通）。上限で切られたら1分は遠い中継で続けて、そのあと中継にもどります。中継を止めたいときは `config.js` に `ebiRelay: false` を足します
- `ebifry/index.html` は、もらったファイルに次の分を足したものです（戦いの計算は変えていません）：格納庫の右上の「‹ 風の芽経済組」・「オンライン（準備中）」のボタンを「🌐 ネット対戦」にして `../config.js`（中継のため）と `net.js` を読みこむ・マイプリセット・上下と視野角の設定・ダブルタップやピンチで拡大しないように
- 3D：three.js（MIT License）。通信：PeerJS（MIT License。ネット対戦を開いたときだけ読みこむ）

## 風の芽製作所：人生すごろく

ルーレット（1〜10）で、うまれてから引退するまでを1駅ずつ進むすごろくです。いちばんお金持ちで引退した人の勝ち。`jinsei/` に入っています（ログインなしで遊べます。ゲームの中のお金（万円）で、所持金は使いません・ふえません）。遊戯 → 風の芽製作所 から開きます。

- 盤は**路線図**：駅がマス、線の色が人生の時期（こども線・大学線・はたらく線・しごと線・起業線・つとめ線・家族線・ふるさと線・とかい線・ゆうやけ線）。ルーレットは駅の**発車標**、できごとは**きっぷ**に出ます
- **遊ぶ人**：CPU と・同じ端末で4人まで（1台をまわして）・**ネット対戦**（4人まで。足りない分は CPU）
- **長さ**：短い（約10分）・ふつう（約15分）・長い（約20分）。4人で遊んだときの目安で、CPU が多いと もっと早くおわります
- **しごと**：就職活動で3枚から1つ。しごとごとに給料と **得意な分野**（鉄道・海・食べもの・まち・ゲーム・けんこう・空・お金・家・株・まなび）。得意な分野の駅では、もらうお金が2倍・はらうお金が0・休まない・一か八かは4以上で当たり
- **分かれ道**：大学線（学費 300万円。給料の高いしごと）か はたらく線、起業線（200万円で会社をつくる。給料日に会社の利益も）か つとめ線、ふるさと線（南陽島）か とかい線（瑠璃市。ふつう・長いだけ）
- 四角い駅（分かれ道・就職活動・結婚・家を買う・引退ターミナル）は、数がのこっていても そこでとまります。給料日は とおるだけでも給料がもらえます
