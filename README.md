# AiliNaX カジノ

架空通貨 **AiliNaX**（アイリナックス）で遊ぶカジノサイトです。Google でログインして遊びます。

> **AiliNaX は架空の通貨です。現金・物・他の通貨・電子マネー・ポイント・ゲーム内アイテムなど、どんなものとも交換できません。売買や交換の持ちかけも禁止です。**

- はじめてログインした人に 1,000 AiliNaX を配ります（1回だけ。追加の配布はありません）
- 残高と勝ち負けの抽選はすべてサーバー（Supabase）で行います。画面から残高を書きかえることはできません
- ゲーム
  - **競馬（目玉）**：3分ごとに1レース。ログインしている全員が同じレースに賭けます（2分間投票 → 30秒レース → 30秒結果）。単勝・複勝、固定オッズ。みんなの投票がリアルタイムで見えます
  - スロット（還元率 約95%）
  - ブラックジャック（6デッキ・ソフト17で止まる・BJは2.5倍・ダブルあり）
  - ルーレット（ヨーロピアン 0〜36）
  - ハイ＆ロー（当てるたびに倍率アップ、好きなときに受け取り）
  - 付属ゲーム：市区町村バトル（`battle/`）
- ランキング・自分の記録・ニックネーム変更

## 設定のしかた（はじめの1回だけ）

ページの公開先（GitHub Pages）：`https://ratecalproject.github.io/tes.1.0.0.8v101/`

1. **Supabase のプロジェクトを作る**　[supabase.com](https://supabase.com) に GitHub か Google で登録し、New project（無料プラン・リージョンは Tokyo がおすすめ）。
2. **サーバー側を入れる**　左の **SQL Editor** → New query に `supabase/schema.sql` の中身をぜんぶ貼って **Run**。「Success」が出ればOK（あとで更新したときも同じように貼りなおして Run。残高は消えません）。
3. **Google ログインを用意する**
   1. Supabase の **Authentication → Sign In / Providers → Google** を開き、そこに出ている **Callback URL**（`https://〇〇.supabase.co/auth/v1/callback`）をコピー。
   2. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作り、**Google Auth Platform**（OAuth 同意画面）でアプリ名などを入れて作成。**対象（Audience）を「本番環境（In production）」に公開**しておく（テストのままだと登録した人しかログインできません）。
   3. **クライアント → クライアントを作成**、種類は「ウェブ アプリケーション」。
      - 承認済みの JavaScript 生成元：`https://ratecalproject.github.io`
      - 承認済みのリダイレクト URI：1. でコピーした Callback URL
   4. できた **クライアント ID** と **クライアント シークレット** を Supabase の Google の画面に貼って、Google を **Enabled** にして保存。
4. **戻り先の URL を登録**　Supabase の **Authentication → URL Configuration** で
   - Site URL：`https://ratecalproject.github.io/tes.1.0.0.8v101/`
   - Redirect URLs に同じ URL を追加
5. **キーを config.js に書く**　Supabase の **Project Settings → API Keys** にある **Publishable key**（または legacy の anon key）と、**Project URL**（Project Settings → Data API などにある `https://〇〇.supabase.co`）を `config.js` に貼って保存（GitHub の画面で config.js を開いて鉛筆マークから編集できます）。
   - **secret / service_role キーは絶対に貼らないでください。** Publishable（anon）キーは公開しても大丈夫なキーです。
6. **GitHub Pages を確認**　リポジトリの Settings → Pages で、Branch が `main` / `(root)` になっていればOK。

うまくいかないとき：ログイン後に真っ白・エラーなら 4. の URL、Google の画面でエラーなら 3. のリダイレクト URI と公開状態を見なおしてください。

## しくみ（メモ）

- 画面（GitHub Pages）は Supabase の関数（RPC）を呼ぶだけです。テーブルは画面から直接読み書きできないようにしてあり、残高の増減・カードの山・抽選・着順は全部サーバーの中で決まります。
- 競馬の着順はレースの投票がしめきられるまで画面に送られません。結果の払い戻しは、レースが終わったあとにだれかがページを見ると自動で行われます（見ている人がいなくても、次にだれかが開いたときに精算されます）。
- 残高をリセット・調整したいときは、Supabase の Table Editor で `profiles` の `balance` を書きかえてください。

## 付属ゲーム：市区町村バトル

日本全国の市区町村の地図で遊ぶ陣取り将棋です。`battle/` に入っています（ログインなしで遊べます）。ブラウザで `battle/index.html` を開くだけでも遊べます。

- 盤：全国1792市区町村（千島列島・南樺太・北方領土・尖閣諸島・沖縄を含む）。地方ごと・都道府県ごとに使う範囲をえらべます（使わない都道府県は灰色）
- 人数：2〜16人（この端末でCPUや交代で／オンライン）
- 対戦のかたち：個人戦／紅白戦（同じ組の領土を通りぬけて攻め込める・同じ町を本拠地にした2人は一緒に脱落）
- 順番：サイコロ／自分で決める（オンラインはホストが決める）
- 政令指定都市・都道府県庁所在地・千代田区は★4以上
- 巡数：おまかせ／1〜999巡を自由に／上限なし
- 本拠地：★4の町から（政令指定都市・都道府県庁所在地・千代田区など）／どこからでも
- 出現場所：ある程度ランダム（ほどよく散らばる・紅白戦は組で集まる）／完全ランダム／選択制（順番に地図で本拠地をえらぶ）
- 最初の町の数：少なめ／ふつう／多め
- 持ち時間（3〜20分）と秒読み（10〜60秒）。時間切れはCPUがかわりに1手指す
- 姉妹都市：国内の姉妹都市・友好都市が自分の駒か無所属なら、離れていても1手で位置を入れ替えられ、相手の能力も使える
- 海外の町を呼ぶ：本拠地以外の自分の駒を★の合計4以上になるように3つまで犠牲にすると、50%の確率で海外の姉妹都市・友好都市や世界の貿易港町が持ち駒としてやってくる（★は人口で4〜6、移動力2、駒に国旗。全部で890の町）
- 町の能力：港町・空港は移動力+1、忍び（相手も飛びこえる）、要塞（囲まれても合併されない）、足止め（となりの相手の移動力-1）、ロケット など
- ことば：日本語・繁體中文🇹🇼・English🇬🇧・Deutsch🇩🇪・한국어🇰🇷・Español🇪🇸・Русский🇷🇺（タイトル画面の国旗で切りかえ。はじめは端末の言語に合わせます。日本語は「ふつう／よみがな（ふりがなつき）／ローマ字つき」をえらべます。町の名前も、中国語は旧字体の漢字、韓国語・ロシア語はその国の書き方、英語・ドイツ語・スペイン語はローマ字で出ます。ことばのちがう人どうしでも同じ部屋で遊べます）
- 表示：自動／スマホ／タブレット／PC（タイトル画面のいちばん下で切りかえ。タブレットは縦向きなら盤の下に2列、横向きなら盤の右に情報）
- オンライン：部屋コード・ランダムマッチ（PeerJS の無料サーバーで端末どうしを直接つなぎ、同時に無料の公開MQTTサーバー（EMQX・HiveMQ・Eclipse・Mosquitto）でも中継します。どれか1つが通れば遊べます。対局中にホストがいなくなったら、残った人がホストを引きつぎます。対局中はリアクション（頑張れ！／どんまい／ごめん／助けて／素晴らしい）を送れます）

地図：国土数値情報（行政区域データ、国土交通省）をもとにスマートニュース メディア研究所が簡略化したデータを加工。南樺太の海岸線は Natural Earth（パブリックドメイン）。
人口・面積：令和2年国勢調査（総務省統計局）。千島列島・南樺太・北方領土の町村は1945年当時の区分をもとにしています（南樺太の町村境界は推定の目安）。
姉妹都市・友好都市（国内・海外）と海外の町の名前・国・人口：ウィキデータ（CC0）。通信：PeerJS（MIT License）。
