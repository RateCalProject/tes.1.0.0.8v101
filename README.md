## 競馬

- **開催**：毎日 16:30・17:30・18:30・19:30 から7レースずつ（8分おき）。回ごとに競馬場が変わります。メインレースは20:30（平日オープン特別、土曜G2・G3、日曜G1）
- **競馬場**：16:30 中京（左回り・直線412m・坂）、17:30 京都（右回り・直線404m・3コーナーに坂）、18:30 府中（左回り・直線525m・坂）、19:30 京都、20:30 府中（メインレース）
- **馬**：同じ馬がずっと走り、戦績が残ります。勝つとクラスが上がり（未勝利→1勝→2勝→3勝→オープン）、重賞・G1はオープンの強い馬だけ。1年＝1か月で年をとり、8歳（勝てなかった馬は4歳）で引退。毎月2歳の新馬が入ってきます。同じ日に2回走ったり、2日続けて走ったりはしません
- **能力**：スピード・スタミナ・脚質（逃げ・先行・差し・追込）・得意な距離・芝/ダート・重い馬場の得意不得意・年齢。逃げ・先行が多いとハイペースで後ろの馬が有利、直線の短い競馬場は前の馬が有利
- **出走表**：枠・馬番・馬名・性齢・騎手・斤量・馬体重（増減）・脚質・近5走・単勝オッズと人気。馬名をタップすると全成績
- **馬券**：単勝・複勝・枠連（9頭以上のとき）・馬連・ワイド・馬単・3連複・3連単。オッズは買った時点で決まる固定オッズ。発売は発走1分前まで
- **人気とオッズ**：「みんなの見立て」から計算しています。調子・ペース・馬体重の大きな増減は入っていないので、出走表を読むと穴馬が見つかることがあります
- **払戻率**：ふだんのレース 単複75%・枠連/馬連/ワイド72.5%・馬単/3連複70%・3連単67.5%、重賞とオープン特別はJRAと同じ（80/77.5/75/72.5%）、G1は高め（85/82.5/80/77.5%）
- **頭数**：ふだん8〜12頭（実力の差が大きく配当は低め）、オープン特別10〜14頭、G2・G3は12〜16頭、G1は16〜18頭（接戦で荒れやすい）

## 税と給付金（ゲームの中だけの税です。実際の税金とは関係ありません）

- 1年＝1か月（日本時間）。毎月1日〜15日に、前の月の分を「役所」タブで申告します
- 所得＝その月の「払い戻し − 賭け金」（マイナスなら0）。はじめての配布と給付金には税金がかかりません
- 税額：所得から基礎控除500を引いた残りに、〜2,000は5%、〜10,000は10%、〜50,000は20%、〜200,000は33%、それより上は45%
- 申告する所得は自分で書きます。16日に税務調査があり、調査される確率は基本10%、ごまかしが大きいほど高くなります（最大90%）。見つかると不足分＋重加算税35%
- 悪質なごまかし（本当の所得の半分以上を隠した・隠した所得が10,000以上・前にも見つかったことがある、のどれか）は、税を納めたあとの残高の7割を没収
- 申告しなかった人：記録から計算して無申告加算税15%
- 期限までに納めなかった分：延滞金10%をつけて残高から差し押さえ。足りない分は当たりが出るたびに差し押さえ
- 給付金500：期限内に申告して期限までに納め、脱税が見つからず、滞納がなく、16日の時点で所持金（残高＋遊んでいる途中の賭け金）が5,000以下の人に入ります（その月にまだ登録していなかった人は対象外）
- 国庫：カジノのもうけ・税金・罰金・没収したお金が入り、給付金が出ていきます。足りないときは国債（マイナス）になります
- 締め（16日）の処理は、16日になってからだれかがページを開いたときに自動で行われます

## サーバー（Supabase）

設定ずみです（プロジェクト `ailinax-casino`、組織 `AiliNaX`、東京リージョン）。

- ページ：`https://ratecalproject.github.io/tes.1.0.0.8v101/`
- ログイン：メールアドレスに届くリンクで入る（パスワードなし）
- **無料プランのメール送信は、サイト全体で1時間に2通まで**です。たくさんの人が同時に新しく登録すると「送りすぎ」と出ます。増やしたいときは Supabase の Authentication → Emails で自分のメールサーバー（SMTP）を設定してください
- サーバー側を更新したとき：Supabase の SQL Editor に `supabase/schema.sql` を貼って Run（何度やっても残高は消えません）
- `config.js` の anon（publishable）キーは公開して大丈夫なキーです。secret / service_role キーは絶対に書かないでください
- 無料プランのプロジェクトは、1週間だれも使わないと一時停止します。Supabase の画面で「Restore」を押せば戻ります

## しくみ（メモ）

- 画面（GitHub Pages）は Supabase の関数（RPC）を呼ぶだけです。テーブルは画面から直接読み書きできないようにしてあり、残高の増減・カードの山・抽選・着順は全部サーバーの中で決まります。
- 競馬の着順は番組をつくるときにサーバーで決まりますが、発走するまで画面には送られません。払い戻しは、レースが終わったあとにだれかが競馬の画面を開くと自動で行われます（見ている人がいなくても、次にだれかが開いたときに精算されます）。
- 競馬を一時的に止めたいときは、`index.html` の `const RACE_ON = true;` を `false` にすると競馬タブが消えます。
- 残高をリセット・調整したいときは、Supabase の Table Editor で `profiles` の `balance` を書きかえてください。

## 付属ゲーム：市区町村バトル

日本全国の市区町村の地図で遊ぶ陣取り将棋です。`battle/` に入っています（ログインなしで遊べます）。ブラウザで `battle/index.html` を開くだけでも遊べます。

- 盤：全国1792市区町村（千島列島・南樺太・北方領土・尖閣諸島・沖縄を含む）。地方ごと・都道府県ごとに使う範囲をえらべます（使わない都道府県は灰色）
- 人数：2〜16人（この端末でCPUや交代で／オンライン）
- 対戦のかたち：個人戦／紅白戦（同じ組の領土を通りぬけて攻め込める・同じ町を本拠地にした2人は一緒に脱落）
- 順番：サイコロ／自分で決める（オンラインはホストが決める）
- 政令指定都市・都道府県庁所在地・千代田区は★4以上
- 巡数：おまかせ／1〜999巡を自由に／上限なし
- 本拠地：★4の町から（政令指定都市・都道府県庁所在地・千代田区など）／どこからでも
- 出現場所：ある程度ランダム（ほどよく散らばる・紅白戦は組で集まる）／完全ランダム／選択制（順番に地図で本拠地をえらぶ）
- 最初の町の数：少なめ／ふつう／多め
- 持ち時間（3〜20分）と秒読み（10〜60秒）。時間切れはCPUがかわりに1手指す
- 姉妹都市：国内の姉妹都市・友好都市が自分の駒か無所属なら、離れていても1手で位置を入れ替えられ、相手の能力も使える
- 海外の町を呼ぶ：本拠地以外の自分の駒を★の合計4以上になるように3つまで犠牲にすると、50%の確率で海外の姉妹都市・友好都市や世界の貿易港町が持ち駒としてやってくる（★は人口で4〜6、移動力2、駒に国旗。全部で890の町）
- 町の能力：港町・空港は移動力+1、忍び（相手も飛びこえる）、要塞（囲まれても合併されない）、足止め（となりの相手の移動力-1）、ロケット など
